# 🛒 Blinkit Sales & Performance Analysis Dashboard (Excel)

An end-to-end data analytics project analyzing Blinkit's retail sales, outlet types, item categories, and regional demand to derive business insights using Microsoft Excel.

---

## 🎯 Project Objective
To clean, model, and visualize raw grocery sales data into an interactive, decision-ready Excel dashboard using Pivot Tables, Charts, and Slicers.

---

## 📌 Key Metrics (KPIs)
| Metric | Value |
| :--- | :--- |
| **Total Sales** | ₹1.20M |
| **Total Items Sold** | 8,523 |
| **Average Rating** | 3.9 / 5.0 |
| **Average Sales / Order** | ₹141 |

---

## 📈 Dashboard Features & Scope of Analysis
- **Fat Content Distribution:** Low Fat vs Regular product sales split.
- **Category-wise Performance:** Top-selling item categories (Fruits, Snacks, Household, Dairy, etc.).
- **Outlet Size & Location:** Sales breakdown across Tier 1, Tier 2, and Tier 3 cities.
- **Outlet Type Comparison:** Revenue contribution of Grocery Stores vs Supermarket Type 1, 2, and 3.
- **Establishment Trend:** Historical outlet setup timeline (2012–2022).

---

## 🛠️ Tools & Skills
- **Tool:** Microsoft Excel (`.xlsx`, `.xlsb`)
- **Features Used:** Pivot Tables, Pivot Charts, Slicers, Data Validation, KPI Cards, Data Cleaning.
